Notes, in plain Markdown.

Naut is a quiet place to write on your Mac. Every note is a .md file you own, and one switch puts it on the web, looking exactly as it does while you write.

Download for Mac Latest · macOS 14+ · Apple silicon
01 — Files

Yours, as plain text.

Notes live in ~/Documents/Naut as ordinary Markdown files. Sync them, grep them, keep them in git. No database, no account, nothing to export.

02 — The page

Math and code, rendered as you type.

Write on the page itself: headings, equations and code take their final shape while the caret is still in them. TeX becomes MathML and code is highlighted when the note renders, so pages need no scripts and work offline.

03 — Publishing

One switch puts it on the web.

Publishing runs on your own Cloudflare account. Naut sets up a Worker and a KV namespace once; after that, the globe button sends a note to naut.<you>.workers.dev. The page readers get is the preview you saw.

Splits and panes

Split right or down, float a pane, maximize one. Keep two notes side by side.

Vim and Helix keys

Modal editing in the live page, with the cursor each mode asks for.

Zen mode

⌃⌘Z hides everything but the note.

Install

Get Naut.

Download

Open the disk image and drag Naut to Applications.

Naut.dmg

Homebrew

Naut's repository is its own tap.

brew tap frinfo702/naut https://github.com/frinfo702/Naut brew install --cask naut

From source

Needs Xcode; Zig comes from the Nix flake.

git clone https://github.com/frinfo702/Naut cd Naut && nix develop -c zig build run

Naut keeps itself current: Naut → Check for Updates… installs the newest release in place.
